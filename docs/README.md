# Documentation

This directory documents GADRA's simulator boundary, real-workload input
contract, and the correspondence between the proposed mechanisms and code.

- `architecture.md` describes capture, replay, and timing accounting.
- `git-msg-tag.md` defines commit message tags.
- `workloads.md` defines the external asset and capture contract.
- `mechanism-correspondence.md` maps A and B to implementation modules and
  reported evidence.

- `evaluation.md` defines fixed splits, all-fragment aggregation, baseline provenance, and local outputs.
- `implementation.md` defines private resource bindings and paired execution records.
